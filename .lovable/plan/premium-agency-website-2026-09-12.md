# Premium agency website

## Build
- Replace the placeholder with a single polished, responsive agency website using the supplied structure and copy.
- Create a crisp light design system with dark typography, a strong cobalt CTA color, restrained lime highlights, subtle borders, and professional motion.
- Add a sticky desktop/mobile navigation, conversion-led hero, trust metrics, ten service cards, featured web-design showcase, and repeated calls to action.
- Build an editable, filterable portfolio from a typed project data array with eight clearly labelled concept projects and locally generated visual previews.
- Add the audit form, benefits, four-step process, value framework, replaceable testimonial placeholders, about section, accessible FAQ accordion, contact form, and footer.

## Interaction and quality
- Validate both forms in the browser and show clear success states without claiming delivery to an external service.
- Ensure navigation, portfolio filters, accordion controls, mobile menu, and all CTA paths work.
- Use semantic headings, labels, keyboard-friendly controls, reduced-motion support, descriptive image text, and route-specific SEO/social metadata.
- Verify the finished page at desktop and mobile sizes, checking layout, interactions, and browser errors.

## Content assumptions
- Keep `[AGENCY NAME]`, contact details, social URLs, metrics, testimonials, and portfolio entries visibly editable placeholders.
- Treat all portfolio items as demo concepts and avoid invented clients, identities, contact details, or performance claims.
